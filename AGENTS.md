# Repository guide

Flashcard Reels is an npm-workspaces Turborepo:

- `apps/mobile` is the Expo/React Native app.
- `apps/web` is the internal Next.js portal deployed to Vercel.
- `packages/design-tokens` is the framework-neutral shared package.

## Canonical commands

Run these from the repository root:

```bash
npm install
npm run dev:mobile
npm run dev:web
npm run check
npm test
npm run check:dead-code
npm run build
npm run verify
```

Root scripts are repository-wide orchestration and CI entry points. When working
inside a workspace, run that workspace's local scripts—for example, `npm run check`,
`npm test`, or `npm run lint` from `apps/mobile` or `apps/web`. Do not
run unrelated workspace validation for routine app-local work.

The mobile package owns Expo commands and the web package owns Next.js commands.
Do not run Expo or Next.js from the repository root with their CLIs directly.

## Configuration ownership

- `.oxlintrc.json` and `.oxfmtrc.json` are the repository-wide lint and format policy.
- `tsconfig.base.json` contains shared TypeScript strictness.
- Workspace `tsconfig.json` files extend the shared base and retain framework-specific
  settings locally. Expo and Next.js configuration must not be forced into each other.
- `turbo.json` owns task dependency and cache behavior; package scripts own the actual
  commands.

`apps/web/next-env.d.ts` is generated by Next.js. Do not edit it manually; run
`npm run typecheck` from `apps/web` when Next.js type references need refreshing.

`knip.json` owns the monorepo dead-code policy. Add executable generators and
other non-imported entry points to package scripts before adding Knip exceptions.

## Generated and ignored state

`.expo`, `.next`, `dist`, and `node_modules` are generated. The only expected Expo
state directory is `apps/mobile/.expo`; a root `.expo` directory is stale and may be
removed when it appears.

Keep Expo Doctor enabled in validation. A Doctor failure should be investigated as
an app/config/dependency issue or an unavailable Expo service, not hidden with a CI
skip or warning setting.
